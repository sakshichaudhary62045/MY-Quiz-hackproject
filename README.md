A simple and interactive Quiz Application built using HTML, CSS, and JavaScript. This app allows users to answer multiple-choice questions and check their knowledge.
Features
Start Quiz interface
10 multiple-choice question
Each question has 4 options

Correct answer shows green

Wrong answer shows red

Next button to move to the next question

Final score displayed at the end

Restart quiz option

🛠️ Technologies Used

HTML – Structure of the quiz

CSS – Styling and layout

JavaScript – Quiz logic and score calculation

▶️ How to Run the Project

Download or clone this repository.

Open the project folder.

Run the Quiz.html file in your browser.

🎯 Project Purpose

This project was created to practice JavaScript concepts like arrays, functions, DOM manipulation, and event handling.
